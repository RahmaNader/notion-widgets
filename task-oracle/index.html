How to export from Notion
  1. Open Tasks or Reoccurring tasks as a full page.
  2. ••• (top right) → Export → format Markdown & CSV → Export.
  3. Unzip the download and drop the …_all.csv file here (it contains every row, not only the current view). An Excel copy of it works too.

Columns used: Name, Time block, Category, Tags, Routine, Priority, Progress, Status, Items, Notes, Link, Day, Optional, Hide. Done/Cancelled and hidden tasks are skipped by default.
